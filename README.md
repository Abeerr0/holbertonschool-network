# Networking Basics

My networking exercises for Holberton School.

- [basics_0](basics_0/): OSI model, network types, addresses, TCP/UDP and ping.
- [basics_1](basics_1/): Hostname mappings, local IP addresses and a TCP listener.

## Requirements

Ubuntu with Bash, net-tools, iproute2, iputils-ping and netcat-openbsd.

```sh
sudo apt-get update
sudo apt-get install -y net-tools iproute2 iputils-ping netcat-openbsd
```

The numbered answer files contain one answer number per line. Bash scripts are executable.
