# Networking Basics 0

| File | Task |
| --- | --- |
| `0-OSI_model` | OSI model questions |
| `1-types_of_network` | LAN, WAN and Internet questions |
| `2-MAC_and_IP_address` | MAC and IP address questions |
| `3-UDP_and_TCP` | TCP and UDP questions |
| `4-TCP_and_UDP_ports` | Show listening sockets and their processes |
| `5-is_the_host_on_the_network` | Ping an address five times |

## Run

```sh
sudo ./4-TCP_and_UDP_ports
./5-is_the_host_on_the_network 8.8.8.8
```

Run the ports script with sudo to see process information for sockets owned by other users.
